# Lemmings 6.7.0

| Host | Worker | Escalation worker | Reviewer | Explorer |
| --- | --- | --- | --- | --- |
| Codex | GPT-6.2 Sol, medium | GPT-6.2 Sol, high | GPT-6.2 Sol, high | GPT-6 Luna, medium |
| Claude Code | Sonnet, medium | Opus, high | Opus, medium | Haiku, medium |

The Codex worker increases reasoning effort when it escalates. Use Astra only when explicitly requested by the user.

Claude Code agent files now include the configured `effort`. The installer, `lemmings agents sync`, and the bundled plugin generate the same settings. Project agents that omit `effort` inherit the host's behavior. For existing copied installations, install the updated skill and sync the agents.

On the Anthropic API, Claude Code 2.1.293 or later resolves all three shipped aliases to the 5.5 models. Other providers may resolve the aliases differently. For a major migration, a project can opt in to a separate Claude worker with `model: "claude-fable-5-2"` and `effort: "medium"` in its agent configuration.

# Lemmings 6.1.0

Lemmings 6.1 adds native host-configured provider routing while keeping runtime schema v5 and the standalone skill-only workflow.

## Provider routing

- Codex runtime routes use the selected user-level Codex profile and no longer need a copied API key or reconstructed provider transport.
- Claude Code is a runtime executor for Anthropic, Bedrock, Vertex, Foundry, host-managed providers, and compatible gateways.
- Codex and Claude Code can dispatch roles through each other's installed CLI.
- Host probes use the selected CLI, confirm model identity when the host exposes it, and report incomplete usage evidence explicitly.
- Provider discovery records sanitized metadata and digests only. It never changes host configuration, stores credentials, or requires an env file.
- Existing direct OpenCode routes and frozen schema-v5 Tasks remain compatible.

## Skill-only

The complete Discover to Plan to Refine to Implement to Verify workflow still works without Python or a runtime bundle. Codex and Claude Code use their native agents and current provider configuration. Inactive hooks return before looking for Python.

## Update

Update only when no runtime Task is active, restart or reload the Codex or Claude plugin, and run the package validation or lemmings doctor for runtime-backed projects.

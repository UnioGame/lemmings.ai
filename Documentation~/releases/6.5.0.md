# Lemmings 6.5.0

Lemmings 6.5 is a deliberate simplification. The workflow stays the same in spirit (scope, plan, implement, independent review, proportional modes). The schema-v5 runtime that surrounded it is removed. This release is not backward compatible and has no migration path.

## Removed

- The Task/Phase/Review JSON lifecycle and everything tied to it: the state machine, revisions and compare-and-set, digests, invocation records, budgets and receipts, readiness gates, v4 migration, and the 58-command CLI.
- Plugin hooks. They ran on every Bash/Agent call (about 0.5 s each on Windows, even when idle) and could be bypassed. Native read-only agent definitions and a post-hoc `scope` check replace them.
- Provider discovery, generated profiles, recovery proposals, `direct` provider mode, and secret handling.
- Templates, historical task artifacts, and the runtime references.

## New shape

- `SKILL.md` is the complete process: Discover → Plan → Implement → Verify, with Simple, Standard, and Parallel modes. The task contract is a short Markdown brief. There are at most two repair rounds.
- The optional helper, `scripts/run.py`, provides four commands:
  - `doctor`;
  - `workspace create|list|remove|estimate`, with safe removal and a large-workspace approval gate;
  - `scope`, which checks the real diff against owned and forbidden paths and handles `..`, renames, and Unicode;
  - `dispatch`, which runs a role on Codex, Claude Code, or OpenCode with a deadline, a run log, a model identity check, and explicit fallback.
- Named agents live in `.agents/lemmings.json` → `agents`. There can be several workers and reviewers, each with a host, a model, a `use` note that guides the manager's choice, a `default` flag, and an `escalateTo` successor for when an agent cannot finish. `agents sync` pins models for native Codex and Claude subagents.
- Role prompts live in `skills/lemmings/roles/*.md`; `agents/*` and per-agent native files are generated from them.
- Telemetry moved to the optional `packages/lemmings-telemetry`, which reads dispatch run logs.
- The installer rolls back only what it changed.

## Upgrade

Replace the old bundle with the new one (reinstall the plugin, or run `install.py`). Delete old `docs/tasks/*.task.json` artifacts and `<git-common-dir>/lemmings/active.json` if they exist; nothing reads them anymore.
